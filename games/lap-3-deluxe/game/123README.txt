# INSTALLATION STEPS 
    (Xdelta is prefered to Pizza Oven as of writing this 24/12/2024):

You'll Need:
1. The .zip file from Gamebanana
2. An xdelta patcher
3. Pizza Tower

1. Extract the .zip, you've probably already done this if you're reading this, so good job. You should see a data.xdelta, 2 NekoPresence.dll's, a "lang" folder, and a "sound" folder.

2. the 2 NekoPresence.dll files can be copy pasted into your Pizza Tower folder
    (If you do not know where that is, you can access it via Steam, Game page >> Settings icon >> Manage >> Browse Local Files. [Unless you pirated the game, but you wouldn't do that... right?])

    (If it asks you to replace existing files, hit "yes")

3. The "lang" folder can also be copy pasted into the Pizza Tower folder. (make sure it is pasted at the top level, where the .exe is). Do NOT delete the original folder!!
    (If asked, you'll need to replace files.)

4. The "sound" folder can once again, also be pasted. Again, don't delete the original!!
    (you can also go into Sound/Desktop, and instead take the Lap3DX folder and paste that into the matching sound/desktop of your Pizza Tower folder. DO NOT TAKE THE BANKS OUT OF THEIR FOLDER)

5. The .xdelta must be put onto your Pizza Tower data.win, VERIFY FILES ON STEAM AS YOU NEED A BASE GAME, 1.1.28 VERSION DATA.WIN TO PATCH.
    Open the xdelta patcher, in "original file" put your data.win, in "xdelta patch" put the .xdelta. It should apply the patch.
        (If it does not, then you likely need to reset your data.win)

    (If you need to verify files, then go to Steam gamepage >> Settings Icon >> Properties >> Installed Files >> Verify Integrity of Files, GAME MUST BE CLOSED FOR THIS TO WORK)

6. The mod should be ready to play, open it and enjoy! :3 ^_^ :p
